# Specification

## Summary
**Goal:** Replace all service card images with professional photos, fix search functionality, and resolve mobile dropdown scrolling issues.

**Planned changes:**
- Replace all 48+ service card images (AC Installation, AC Gas Refill, Tap Repair, Furniture Repair, Door & Window Fixing, and all others) with real professional photos of technicians performing services
- Implement real-time search filtering with dropdown results showing matching services by name, category, and description
- Fix mobile dropdown scrolling for service category filters and all dropdowns throughout the application with proper touch scrolling and preventing background page scroll

**User-visible outcome:** Users will see realistic, professional photos on every service card instead of cartoons, blank images, or broken placeholders. The search bar will display filtered results in a dropdown as they type, and all dropdowns will scroll smoothly on mobile devices without the page scrolling behind them.
